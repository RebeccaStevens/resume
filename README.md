# Rebecca Stevens – Resume

[![Build PDF](https://github.com/RebeccaStevens/resume/actions/workflows/build-pdf.yml/badge.svg)](https://github.com/RebeccaStevens/resume/actions/workflows/build-pdf.yml)

Source files for my resume, written in Markdown and rendered to PDF via [WeasyPrint](https://weasyprint.org/).

> **Note:** Private contact information (such as phone number) is omitted from this public repository and its public builds.

## Download

- **Latest PDF:** [Download `Rebecca Stevens - Resume.pdf`](https://github.com/RebeccaStevens/resume/releases/latest/download/Rebecca.Stevens.-.Resume.pdf)
- **GitHub Actions Builds:** [Browse Workflow Runs](https://github.com/RebeccaStevens/resume/actions/workflows/build-pdf.yml)

## Build Locally

```bash
pip install -r requirements.txt
python3 src/render.py
```
